## Objetivo

Convierte "se ve bien" en números. Vas a completar el golden dataset que empezaste en `02-chunking/` (30+ preguntas sobre el corpus hipotecario, ahora con respuestas de referencia), ejecutar tu pipeline de `05-reranking` sobre él y puntuarlo con Ragas (faithfulness, answer relevance, context precision, context recall) más hit@5 determinista. Luego compararás dos configuraciones del pipeline y escribirás un reporte breve de evaluación.

Esta carpeta se convierte en la semilla de la suite de evals del proyecto final y del Módulo 3. Constrúyela como si otras personas fueran a ejecutarla: un solo comando, reproducible y versionada.

Carpeta: `rag-lab/06-evals/`.

**Time box:** 90 minutos. Más o menos 35 minutos para el dataset, 30 para el runner y 25 para el análisis y el reporte. No te saltes el análisis; es la parte por la que preguntan en las entrevistas.

## Requisitos del dataset

No empieces de cero. Tu golden set viene creciendo desde `02-chunking/data/golden.jsonl` (25+ preguntas etiquetadas con `expected_doc_id` y `expected_section`), se extendió en `04-hybrid/data/golden_hybrid.jsonl` con `category` (exact_term, filtered, paraphrase) y `filters`, y en `05-reranking/` con filas `follow_up`. Copia `05-reranking/data/golden_rerank.jsonl` a `06-evals/data/golden.jsonl` y agrega lo que necesitan las métricas de generación. Un ítem terminado:

```json
{"id": "gift-007", "question": "In a loan with a 2025 application date, could the gift come from the borrower's employer?",
 "expected_doc_id": "fha-gift-funds_v2", "expected_section": "3.2 Acceptable Donors",
 "category": "filtered", "filters": {"jurisdictions": ["US"], "as_of": "2025-06-30"},
 "reference": "No. Under the 2024 policy (v2), in force until the 2026 update, employers were not acceptable donors.",
 "difficulty": "lookup", "answerable": true}
```

Requisitos:

- Al menos 30 ítems en total, cada uno con una `reference` escrita a partir del documento fuente y una `difficulty`.
- Al menos 5 ítems `multi_hop` (la respuesta necesita dos secciones) y 3 `numeric` (un cálculo o umbral).
- Al menos 2 ítems que prueben las versiones de la política de fondos de regalo de FHA: uno respondido por la v3 vigente (2026) y otro con un filtro `as_of` que seleccione la v2 (2024).
- Al menos 4 ítems con `answerable: false`, `expected_doc_id: null` y la referencia "The policies do not cover this."
- Cada par `expected_doc_id` + `expected_section` debe existir en tus tablas `documents` y `chunks`. Escribe un pequeño script que lo verifique.

```python
# 06-evals/golden.py
from __future__ import annotations

import json
from pathlib import Path
from typing import Literal

from pydantic import BaseModel, Field


class GoldenItem(BaseModel):
    id: str
    question: str
    reference: str
    expected_doc_id: str | None = None      # None for unanswerable items
    expected_section: str | None = None
    category: Literal["exact_term", "filtered", "paraphrase", "follow_up", "general"] = "general"
    filters: dict = Field(default_factory=dict)
    history: list[dict] = Field(default_factory=list)
    reference: str
    difficulty: Literal["lookup", "multi_hop", "numeric"]
    answerable: bool = True


def load_golden(path: Path = Path("data/golden.jsonl")) -> list[GoldenItem]:
    items = [GoldenItem.model_validate_json(line) for line in path.read_text("utf-8").splitlines() if line.strip()]
    ids = [i.id for i in items]
    assert len(ids) == len(set(ids)), "duplicate ids in golden set"
    return items


class RunRecord(BaseModel):
    item_id: str
    answer: str
    answer_found: bool
    retrieved_sources: list[tuple[str, str]]   # (doc_id, section), best-first
    retrieved_texts: list[str]
    latency_ms: float


def save_run(records: list[RunRecord], path: Path) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text("\n".join(r.model_dump_json() for r in records), "utf-8")
```
