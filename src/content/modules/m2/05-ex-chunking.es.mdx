## Objetivo

Deja de adivinar tamaños de chunk. En este ejercicio construyes un pequeño benchmark de retrieval y lo usas para comparar cuatro configuraciones de chunking sobre tu corpus hipotecario. El resultado es una tabla en tu README que justifica la estrategia de chunking que llevarás al proyecto final.

Carpeta: `rag-lab/02-chunking/`. Entrada: `01-ingestion/out/documents.jsonl` del ejercicio anterior.

### Qué estás midiendo

Estás evaluando **solo el retrieval**, sin generación con LLM. Para cada pregunta de un golden set pequeño sabes qué sección de qué documento contiene la respuesta. Una configuración es buena si esa sección aparece cerca del inicio de los resultados.

- **Hit rate@k** (también llamado recall@k cuando hay un solo elemento relevante): fracción de preguntas donde al menos un chunk de la sección esperada está en el top k.
- **MRR** (mean reciprocal rank): promedio de `1 / rank` del primer chunk relevante; 0 si no aparece en el top k. Premia rankear primero el chunk correcto.
- **Proxies de costo:** número de chunks, tokens promedio por chunk y tokens de contexto promedio enviados con `k = 4`.

Es el equivalente en retrieval de una suite de tests con tasa de aprobación. Reutilizarás la misma idea de golden set, mucho más grande, en la lección 15 y en el Módulo 3.

### Las configuraciones

1. `fixed-800` — tamaño fijo, 800 caracteres, 100 de overlap.
2. `recursive-800` — `RecursiveCharacterTextSplitter`, 800 caracteres, 100 de overlap.
3. `recursive-tok-256` — recursivo con tamaño en tokens, 256 tokens, 32 de overlap.
4. `structure` — consciente del documento: un chunk por sección (par FAQ, sección numerada de política), secciones largas divididas recursivamente por dentro, ruta de títulos antepuesta.

Quinta opcional: `semantic` con `SemanticChunker`, si tienes tiempo y presupuesto.

```python
# 02-chunking/chunkbench/metrics.py
from collections.abc import Sequence


def first_relevant_rank(retrieved: Sequence[dict], doc_id: str, section: str) -> int | None:
    for rank, chunk in enumerate(retrieved, start=1):
        if chunk["doc_id"] == doc_id and chunk["section"] == section:
            return rank
    return None


def hit_at_k(ranks: list[int | None], k: int) -> float:
    return sum(1 for r in ranks if r is not None and r <= k) / len(ranks)


def mrr_at_k(ranks: list[int | None], k: int) -> float:
    return sum(1 / r for r in ranks if r is not None and r <= k) / len(ranks)
```

```python
# 02-chunking/chunkbench/embed_cache.py
import hashlib
import json
import os
from pathlib import Path

import numpy as np
from openai import OpenAI

MODEL = os.getenv("EMBEDDING_MODEL", "text-embedding-3-small")  # example
CACHE = Path(".cache/embeddings.jsonl")


class CachedEmbedder:
    def __init__(self) -> None:
        self.client = OpenAI()
        self.cache: dict[str, list[float]] = {}
        if CACHE.exists():
            for line in CACHE.read_text(encoding="utf-8").splitlines():
                row = json.loads(line)
                self.cache[row["key"]] = row["vec"]

    def _key(self, text: str) -> str:
        return hashlib.sha256(f"{MODEL}\n{text}".encode()).hexdigest()

    def embed(self, texts: list[str], batch_size: int = 128) -> np.ndarray:
        missing = [t for t in dict.fromkeys(texts) if self._key(t) not in self.cache]
        CACHE.parent.mkdir(parents=True, exist_ok=True)
        with CACHE.open("a", encoding="utf-8") as f:
            for i in range(0, len(missing), batch_size):
                batch = missing[i : i + batch_size]
                resp = self.client.embeddings.create(model=MODEL, input=batch)
                for text, item in zip(batch, resp.data):
                    key = self._key(text)
                    self.cache[key] = item.embedding
                    f.write(json.dumps({"key": key, "vec": item.embedding}) + "\n")
        vecs = np.array([self.cache[self._key(t)] for t in texts], dtype=np.float32)
        return vecs / np.linalg.norm(vecs, axis=1, keepdims=True)
```

```python
# 02-chunking/chunkbench/search.py
import numpy as np


def top_k(query_vec: np.ndarray, chunk_vecs: np.ndarray, k: int) -> list[int]:
    scores = chunk_vecs @ query_vec            # cosine, vectors are normalized
    idx = np.argpartition(-scores, min(k, len(scores) - 1))[:k]
    return idx[np.argsort(-scores[idx])].tolist()
```
