## About this exam

This exam checks that you can design, debug and evaluate a RAG system, not just name its parts. It covers the whole module:

- Ingestion and cleaning of PDFs, HTML and policy documents
- Chunking strategies and their trade-offs
- Embeddings: model choice, dimensions, normalization and cost
- Vector stores, with a focus on pgvector operators and indexes
- Hybrid search (BM25 + vectors), reciprocal rank fusion and metadata filtering
- Re-ranking with cross-encoders and query rewriting (multi-query, HyDE, step-back, condensation)
- Citations, grounding and RAG failure modes
- Evaluation with Ragas and DeepEval: faithfulness, answer relevance, context precision and recall
- Caching and cost control

**Format:** 20 questions. Single choice, multi-select, "order the steps" and short code-reading questions. You have 30 minutes. The passing score is **70%**, and passing unlocks Module 3.

**How to prepare:**

1. Re-read the "Common mistakes" section of each concept lesson. Many questions are built on them.
2. Be able to explain which metric detects which failure mode.
3. Read the SQL and Python in lessons 10, 13 and 17 once more; code questions use the same patterns.

Options are shuffled on every attempt. Read each explanation after you submit, even for questions you got right.
