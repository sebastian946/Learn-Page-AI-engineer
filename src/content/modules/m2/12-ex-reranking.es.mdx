## Objetivo

Tu retriever híbrido de `04-hybrid/` devuelve los chunks correctos en algún lugar del top 50, pero no siempre en el top 5. En este ejercicio agregas una segunda etapa: un re-ranker cross-encoder más un paso de reescritura de consultas (condensación de conversación y multi-query). Luego demuestras, con números, si cada pieza ayuda.

Trabajarás en una carpeta nueva: `rag-lab/05-reranking/`. Reutiliza la base de datos pgvector y el corpus hipotecario que indexaste en `03-pgvector/`, y la función de búsqueda híbrida de `04-hybrid/`.

Piénsalo como agregar una nueva capa a un pipeline de pruebas: no la mergeas hasta tener un reporte de antes y después.

**Time box:** 60 minutos. Si se te acaba el tiempo, entrega primero el re-ranker y el benchmark; multi-query es el objetivo extra.

## Qué vas a construir

1. `reranker.py` — un protocolo `Reranker` con dos implementaciones: `CrossEncoderReranker` (local, `cross-encoder/ms-marco-MiniLM-L-6-v2`) y `CohereReranker` (opcional, solo si tienes API key).
2. `rewrite.py` — `condense(history, question)` y `multi_query(question, n=3)` usando `claude-haiku-5-5` con salida JSON validada con Pydantic.
3. `pipeline.py` — `retrieve(question, history)` que ejecuta: condensar → multi-query → búsqueda híbrida por consulta → merge con RRF → re-rank → top-k.
4. `bench.py` — compara cuatro configuraciones sobre un pequeño set etiquetado e imprime una tabla.

El set etiquetado es un archivo JSONL de 20 preguntas, cada una con los `chunk_id` que contienen la respuesta. Escribe las preguntas tú mismo a partir del corpus hipotecario: límites de DTI, fondos de regalo, requisitos de reservas, periodos de espera de FHA, elegibilidad de condominios, política de rate-lock. Incluye al menos 5 preguntas de seguimiento con un historial corto de chat, porque ahí es donde la condensación demuestra su valor.

# 05-reranking/bench.py (metrics helpers)
import statistics


def recall_at_k(retrieved: list[str], relevant: set[str], k: int) -> float:
    return len(set(retrieved[:k]) & relevant) / len(relevant) if relevant else 0.0


def mrr_at_k(retrieved: list[str], relevant: set[str], k: int) -> float:
    for rank, cid in enumerate(retrieved[:k], start=1):
        if cid in relevant:
            return 1.0 / rank
    return 0.0


def p95(values: list[float]) -> float:
    return statistics.quantiles(values, n=20)[18] if len(values) >= 20 else max(values)
