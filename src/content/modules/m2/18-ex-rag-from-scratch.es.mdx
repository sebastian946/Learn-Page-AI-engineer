## Objetivo

Reconstruye tu pipeline RAG sin framework: `httpx` (o el SDK del proveedor) para embeddings, `psycopg` + `pgvector` para almacenamiento y retrieval híbrido, `numpy` donde necesites matemática vectorial, y el SDK de Anthropic para la generación. Todo el núcleo debe caber en **menos de 300 líneas** de código de aplicación (sin contar tests).

Luego demuestra que no es un juguete: ejecútalo contra el golden dataset de `06-evals/` y compara sus scores con tu pipeline de LangChain. Mismos datos, mismo juez, dos implementaciones. Si la versión sin framework queda a pocos puntos y tiene menos piezas móviles, tienes una historia de portafolio sólida.

Carpeta: `rag-lab/07-from-scratch/`.

**Time box:** 90 minutos. Reutiliza tu SQL de la lección 17 y tu validador de citas de la lección 13. No reimplementes el re-ranker; importa el `CrossEncoderReranker` de `05-reranking/` o hazlo opcional.

## Requisitos

El paquete expone un CLI con dos comandos:

```bash
uv run python -m ragcore ingest data/chunks.jsonl     # embeds and upserts chunks
uv run python -m ragcore ask "Can gift funds be used for an investment property?" --product conventional
```

La salida de `ask` imprime la respuesta, las citas (ID de chunk, documento, sección, página) y un resumen de trace en una línea: latencia de retrieval, latencia de generación, tokens de entrada y salida, y costo estimado.

# 07-from-scratch/tests/test_constraints.py
import ast
from pathlib import Path

PKG = Path(__file__).parent.parent / "ragcore"
BANNED = ("langchain", "llama_index", "haystack")


def test_no_framework_imports() -> None:
    for path in PKG.rglob("*.py"):
        tree = ast.parse(path.read_text("utf-8"))
        for node in ast.walk(tree):
            names = []
            if isinstance(node, ast.Import):
                names = [a.name for a in node.names]
            elif isinstance(node, ast.ImportFrom) and node.module:
                names = [node.module]
            assert not any(n.startswith(BANNED) for n in names), f"{path}: framework import {names}"


def test_under_300_lines() -> None:
    total = 0
    for path in PKG.rglob("*.py"):
        lines = [l.strip() for l in path.read_text("utf-8").splitlines()]
        total += sum(1 for l in lines if l and not l.startswith("#"))
    assert total < 300, f"ragcore has {total} lines"
