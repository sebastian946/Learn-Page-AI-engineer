## Objetivo

Construye la etapa de ingesta del asistente de conocimiento hipotecario como un CLI pequeño y con tests. Lee una carpeta de PDFs de políticas de préstamo, guías de underwriting y páginas FAQ en HTML, los limpia, extrae metadata, deduplica y escribe un documento normalizado por línea en `out/documents.jsonl`. Todos los ejercicios posteriores de `rag-lab` leen este archivo, así que la calidad aquí rinde durante el resto del módulo.

Esta es la primera carpeta de tu repo `rag-lab`: `01-ingestion/`.

### El corpus

Necesitas un corpus realista pero ficticio. No uses documentos reales de clientes ni de prestamistas. Crea 8–12 archivos en `01-ingestion/data/raw/`:

- 4–6 **PDFs de políticas** (2–10 páginas cada uno), por ejemplo `policies/US/conventional-dti-limits_v2_2026-02-01.pdf`, `policies/TX/home-equity-50a6_v1_2025-09-15.pdf`. Incluye un encabezado repetido, un pie de página con "Page N of M", secciones numeradas (`4.2 Debt-to-Income Limits`) y al menos una tabla (rango de credit score vs. LTV máximo).
- 2 **versiones de la misma política** (por ejemplo FHA gift funds v2 2024 y v3 2026) con una regla que cambió.
- 1 **duplicado exacto** de un PDF con otro nombre de archivo.
- 2–3 **páginas FAQ en HTML** con nav, footer, un banner de cookies y preguntas en `h2`/`h3`.

Genera los PDFs con `reportlab` o escríbelos en un procesador de texto y expórtalos. Quince minutos de diseño del corpus ahorran horas después: reutilizarás estos archivos para construir preguntas doradas en la lección 15.

# 01-ingestion/ingest/models.py
from datetime import date
from typing import Literal
from pydantic import BaseModel, Field

DocType = Literal["policy", "underwriting_guideline", "faq", "rate_sheet"]

class Section(BaseModel):
    heading: str
    level: int = 1
    text: str
    page: int | None = None

class NormalizedDoc(BaseModel):
    doc_id: str
    source: str
    title: str
    doc_type: DocType
    jurisdiction: str | None = None
    effective_date: date | None = None
    version: str | None = None
    content_hash: str
    is_current: bool = True
    sections: list[Section] = Field(default_factory=list)
```

# 01-ingestion/ingest/__main__.py
import hashlib
import json
import sys
from pathlib import Path

from .clean import clean_pages          # TODO: implement
from .metadata import from_path         # TODO: implement
from .models import NormalizedDoc
from .parse_html import parse_faq       # TODO: implement
from .parse_pdf import parse_pdf        # TODO: implement -> (title, list[Section])


def sha256(text: str) -> str:
    return hashlib.sha256(text.encode("utf-8")).hexdigest()


def ingest(raw_dir: Path) -> list[NormalizedDoc]:
    docs: list[NormalizedDoc] = []
    for path in sorted(raw_dir.rglob("*")):
        if path.suffix.lower() not in {".pdf", ".html"}:
            continue
        rel = path.relative_to(raw_dir).as_posix()
        meta = from_path(rel)
        if path.suffix.lower() == ".pdf":
            title, sections = parse_pdf(path)
        else:
            title, sections = parse_faq(path.read_text(encoding="utf-8"))
        body = "\n".join(s.text for s in sections)
        docs.append(NormalizedDoc(
            doc_id=sha256(f"{rel}:{meta.get('version')}")[:16],
            source=rel, title=title, sections=sections,
            content_hash=sha256(body), **meta,
        ))
    # TODO: dedupe by content_hash, then mark is_current per (title, jurisdiction)
    return docs


if __name__ == "__main__":
    raw, out = Path(sys.argv[1]), Path(sys.argv[2])
    out.parent.mkdir(parents=True, exist_ok=True)
    docs = ingest(raw)
    with out.open("w", encoding="utf-8") as f:
        for d in docs:
            f.write(d.model_dump_json() + "\n")
    print(json.dumps({"written": len(docs)}))
```
