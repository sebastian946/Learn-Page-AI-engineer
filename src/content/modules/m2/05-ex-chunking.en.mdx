## Goal

Stop guessing chunk sizes. In this exercise you build a small retrieval benchmark and use it to compare four chunking configurations on your mortgage corpus. The output is a results table in your README that justifies the chunking strategy you will carry into the capstone.

Folder: `rag-lab/02-chunking/`. Input: `01-ingestion/out/documents.jsonl` from the previous exercise.

### What you are measuring

You are evaluating **retrieval only**, no LLM generation. For each question in a small golden set you know which section of which document contains the answer. A configuration is good if that section shows up near the top of the results.

- **Hit rate@k** (also called recall@k when there is one relevant item): fraction of questions where at least one chunk from the expected section is in the top k.
- **MRR** (mean reciprocal rank): average of `1 / rank` of the first relevant chunk; 0 if not found in the top k. Rewards ranking the right chunk first.
- **Cost proxies:** number of chunks, mean tokens per chunk, and mean context tokens sent for `k = 4`.

This is the retrieval equivalent of a test suite with a pass rate. You will reuse the same golden-set idea, much larger, in lesson 15 and in Module 3.

### The configurations

1. `fixed-800` — fixed-size, 800 characters, 100 overlap.
2. `recursive-800` — `RecursiveCharacterTextSplitter`, 800 characters, 100 overlap.
3. `recursive-tok-256` — recursive with token sizing, 256 tokens, 32 overlap.
4. `structure` — document-aware: one chunk per section (FAQ pair, numbered policy section), long sections split recursively inside, heading path prepended.

Optional fifth: `semantic` with `SemanticChunker`, if you have time and budget.

```python
from collections.abc import Sequence


def first_relevant_rank(retrieved: Sequence[dict], doc_id: str, section: str) -> int | None:
    for rank, chunk in enumerate(retrieved, start=1):
        if chunk["doc_id"] == doc_id and chunk["section"] == section:
            return rank
    return None


def hit_at_k(ranks: list[int | None], k: int) -> float:
    return sum(1 for r in ranks if r is not None and r <= k) / len(ranks)


def mrr_at_k(ranks: list[int | None], k: int) -> float:
    return sum(1 / r for r in ranks if r is not None and r <= k) / len(ranks)
```

```python
# 02-chunking/chunkbench/embed_cache.py
import hashlib
import json
import os
from pathlib import Path

import numpy as np
from openai import OpenAI

MODEL = os.getenv("EMBEDDING_MODEL", "text-embedding-3-small")  # example
CACHE = Path(".cache/embeddings.jsonl")


class CachedEmbedder:
    def __init__(self) -> None:
        self.client = OpenAI()
        self.cache: dict[str, list[float]] = {}
        if CACHE.exists():
            for line in CACHE.read_text(encoding="utf-8").splitlines():
                row = json.loads(line)
                self.cache[row["key"]] = row["vec"]

    def _key(self, text: str) -> str:
        return hashlib.sha256(f"{MODEL}\n{text}".encode()).hexdigest()

    def embed(self, texts: list[str], batch_size: int = 128) -> np.ndarray:
        missing = [t for t in dict.fromkeys(texts) if self._key(t) not in self.cache]
        CACHE.parent.mkdir(parents=True, exist_ok=True)
        with CACHE.open("a", encoding="utf-8") as f:
            for i in range(0, len(missing), batch_size):
                batch = missing[i : i + batch_size]
                resp = self.client.embeddings.create(model=MODEL, input=batch)
                for text, item in zip(batch, resp.data):
                    key = self._key(text)
                    self.cache[key] = item.embedding
                    f.write(json.dumps({"key": key, "vec": item.embedding}) + "\n")
        vecs = np.array([self.cache[self._key(t)] for t in texts], dtype=np.float32)
        return vecs / np.linalg.norm(vecs, axis=1, keepdims=True)
```

```python
# 02-chunking/chunkbench/search.py
import numpy as np


def top_k(query_vec: np.ndarray, chunk_vecs: np.ndarray, k: int) -> list[int]:
    scores = chunk_vecs @ query_vec            # cosine, vectors are normalized
    idx = np.argpartition(-scores, min(k, len(scores) - 1))[:k]
    return idx[np.argsort(-scores[idx])].tolist()
```
