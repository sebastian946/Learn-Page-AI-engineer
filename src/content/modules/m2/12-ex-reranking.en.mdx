## Goal

Your hybrid retriever from `04-hybrid/` (40 candidates per leg, filters inside each leg, RRF with k = 60) returns the right section somewhere in the fused list, but not always in the top 5. In this exercise you add a second stage: a cross-encoder re-ranker plus a query-rewriting step (conversation condensation and multi-query). Then you prove, with numbers, whether each piece helps.

You will work in a new folder: `rag-lab/05-reranking/`. It reuses the same compose stack (`pgvector/pgvector:pg17`), the `documents` and `chunks` tables you indexed in `03-pgvector/`, and the `hybrid_search`, `Filters` and `rrf` code from `04-hybrid/`.

Think of it like adding a new layer to a test pipeline: you do not merge it until you have a before/after report.

**Time box:** 60 minutes. If you run out of time, ship the re-ranker and the benchmark first; multi-query is the stretch goal.

## What you will build

1. `reranker.py` — a `Reranker` protocol with two implementations: `CrossEncoderReranker` (local, `cross-encoder/ms-marco-MiniLM-L-6-v2`) and `CohereReranker` (optional, only if you have an API key).
2. `rewrite.py` — `condense(history, question)` and `multi_query(question, n=3)` using `claude-haiku-5-5` with JSON output validated by Pydantic.
3. `pipeline.py` — `retrieve(question, history)` that runs: condense → multi-query → hybrid search per query → RRF merge → re-rank → top-k.
4. `bench.py` — compares four configurations on the extended golden set and prints a table.

Do not start a new labeled set from zero. Copy `04-hybrid/data/golden_hybrid.jsonl` (rows with `question`, `expected_doc_id`, `expected_section`, `category` and optional `filters`) to `05-reranking/data/golden_rerank.jsonl` and extend it with a new category, `follow_up`: at least 6 questions with a short `history` array that only make sense with that history. Example: history about FHA gift funds, then "and what changed in the 2026 version?". That is where condensation earns its keep. Relevance stays judged by `doc_id` + `section`, exactly as in `02-chunking/`.

# 05-reranking/bench.py (metrics helpers)
import statistics


from reranker import Candidate


def is_hit(c: Candidate, row: dict) -> bool:
    # same relevance rule as 02-chunking: judged by metadata, not text
    return c.doc_id == row["expected_doc_id"] and c.section == row["expected_section"]


def hit_at_k(results: list[Candidate], row: dict, k: int) -> float:
    return 1.0 if any(is_hit(c, row) for c in results[:k]) else 0.0


def mrr_at_k(results: list[Candidate], row: dict, k: int) -> float:
    for rank, c in enumerate(results[:k], start=1):
        if is_hit(c, row):
            return 1.0 / rank
    return 0.0


def p95(values: list[float]) -> float:
    return statistics.quantiles(values, n=20)[18] if len(values) >= 20 else max(values)
