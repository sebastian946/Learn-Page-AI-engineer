## Goal

Your hybrid retriever from `04-hybrid/` returns the right chunks somewhere in the top 50, but not always in the top 5. In this exercise you add a second stage: a cross-encoder re-ranker plus a query-rewriting step (conversation condensation and multi-query). Then you prove, with numbers, whether each piece helps.

You will work in a new folder: `rag-lab/05-reranking/`. It reuses the pgvector database and the mortgage corpus you indexed in `03-pgvector/`, and the hybrid search function from `04-hybrid/`.

Think of it like adding a new layer to a test pipeline: you do not merge it until you have a before/after report.

**Time box:** 60 minutes. If you run out of time, ship the re-ranker and the benchmark first; multi-query is the stretch goal.

## What you will build

1. `reranker.py` — a `Reranker` protocol with two implementations: `CrossEncoderReranker` (local, `cross-encoder/ms-marco-MiniLM-L-6-v2`) and `CohereReranker` (optional, only if you have an API key).
2. `rewrite.py` — `condense(history, question)` and `multi_query(question, n=3)` using `claude-haiku-5-5` with JSON output validated by Pydantic.
3. `pipeline.py` — `retrieve(question, history)` that runs: condense → multi-query → hybrid search per query → RRF merge → re-rank → top-k.
4. `bench.py` — compares four configurations on a small labeled set and prints a table.

The labeled set is a JSONL file of 20 questions, each with the `chunk_id`s that contain the answer. Write the questions yourself from the mortgage corpus: DTI limits, gift funds, reserve requirements, FHA waiting periods, condo eligibility, rate-lock policy. Include at least 5 follow-up questions with a short chat history, because that is where condensation earns its keep.

# 05-reranking/bench.py (metrics helpers)
import statistics


def recall_at_k(retrieved: list[str], relevant: set[str], k: int) -> float:
    return len(set(retrieved[:k]) & relevant) / len(relevant) if relevant else 0.0


def mrr_at_k(retrieved: list[str], relevant: set[str], k: int) -> float:
    for rank, cid in enumerate(retrieved[:k], start=1):
        if cid in relevant:
            return 1.0 / rank
    return 0.0


def p95(values: list[float]) -> float:
    return statistics.quantiles(values, n=20)[18] if len(values) >= 20 else max(values)
