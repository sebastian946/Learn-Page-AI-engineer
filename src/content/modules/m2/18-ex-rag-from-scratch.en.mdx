## Goal

Rebuild your RAG pipeline with no framework: `httpx` (or the provider SDK) for embeddings, `psycopg` + `pgvector` for storage and hybrid retrieval, `numpy` where you need vector math, and the Anthropic SDK for generation. The whole core must fit in **under 300 lines** of application code (tests excluded).

Then prove it is not a toy: run it against the golden dataset from `06-evals/` and compare its scores with your LangChain pipeline. Same data, same judge, two implementations. If the framework-free version scores within a few points and has fewer moving parts, you have a strong portfolio story.

Folder: `rag-lab/07-from-scratch/`.

**Time box:** 90 minutes. Reuse your SQL from lesson 17 and your citation validator from lesson 13. Do not re-implement the re-ranker; import the `CrossEncoderReranker` from `05-reranking/` or make it optional.

## Requirements

The package exposes one CLI with two commands:

```bash
uv run python -m ragcore ingest data/chunks.jsonl     # embeds and upserts chunks
uv run python -m ragcore ask "Can gift funds be used for an investment property?" --product conventional
```

The `ask` output prints the answer, the citations (chunk ID, document, section, page) and a one-line trace summary: retrieval latency, generation latency, input and output tokens, estimated cost.

```python
# 07-from-scratch/tests/test_constraints.py
import ast
from pathlib import Path

PKG = Path(__file__).parent.parent / "ragcore"
BANNED = ("langchain", "llama_index", "haystack")


def test_no_framework_imports() -> None:
    for path in PKG.rglob("*.py"):
        tree = ast.parse(path.read_text("utf-8"))
        for node in ast.walk(tree):
            names = []
            if isinstance(node, ast.Import):
                names = [a.name for a in node.names]
            elif isinstance(node, ast.ImportFrom) and node.module:
                names = [node.module]
            assert not any(n.startswith(BANNED) for n in names), f"{path}: framework import {names}"


def test_under_300_lines() -> None:
    total = 0
    for path in PKG.rglob("*.py"):
        lines = [l.strip() for l in path.read_text("utf-8").splitlines()]
        total += sum(1 for l in lines if l and not l.startswith("#"))
    assert total < 300, f"ragcore has {total} lines"
```
