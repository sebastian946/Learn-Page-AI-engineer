**Escenario (estilo certificación).** El equipo de reclamos quiere lanzar el prompt `v2` de su cadena de preguntas y respuestas sobre pólizas. Antes de aprobarlo, el tech lead pide evidencia: "Muéstrame que v2 es al menos tan correcto y fundamentado como v1, que cita fuentes y que se mantiene dentro del presupuesto de latencia. Usa MLflow para que podamos comparar corridas después."

Vas a trazar una pequeña cadena RAG, evaluar dos versiones de prompt con `mlflow.genai.evaluate` usando jueces LLM integrados, un scorer `Guidelines` y dos scorers personalizados con código, comparar las corridas y escribir una recomendación.

Funciona con **MLflow local** (`mlflow ui` o `mlflow server`) usando Anthropic u OpenAI como modelo de la app y juez, o en **Databricks** con endpoints de serving.

**Tiempo:** 75–90 minutos.

```python
# rag_chain.py
import os
import time

import anthropic
import mlflow
from mlflow.entities import SpanType

mlflow.anthropic.autolog()
client = anthropic.Anthropic()
APP_MODEL = os.environ.get("APP_MODEL", "claude-haiku-5-5")

PROMPTS = {
    "v1": "Answer the question using the context.",
    "v2": ("Answer only from the context. Cite each claim as [doc_id]. "
           "If the context does not contain the answer, say you do not have enough information."),
}

@mlflow.trace(span_type=SpanType.RETRIEVER)
def retrieve(question: str, k: int = 4) -> list[dict]:
    from retriever import search          # exercise 10 retriever, or the in-memory fallback
    return [{"page_content": h.content, "metadata": {"doc_uri": h.doc_id, "chunk_id": h.chunk_id}}
            for h in search(question, k=k)]

@mlflow.trace
def answer(question: str, prompt_version: str = "v1") -> str:
    docs = retrieve(question)
    context = "\n\n".join(f"[{d['metadata']['doc_uri']}] {d['page_content']}" for d in docs)
    msg = client.messages.create(
        model=APP_MODEL,
        max_tokens=400,
        system=PROMPTS[prompt_version],
        messages=[{"role": "user", "content": f"Context:\n{context}\n\nQuestion: {question}"}],
    )
    return msg.content[0].text
```
