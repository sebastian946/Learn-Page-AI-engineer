## Objetivo

Construye un pequeño CLI de triage de tickets sobre Jev y pruébalo como probarías cualquier cliente HTTP: con respuestas grabadas y sin red. Dado un ticket, el CLI hace tres preguntas en **una** request (Choice de departamento, Score de frustración, Noul de urgencia), imprime una decisión tipada y se comporta correctamente cuando la API devuelve 422 o 429.

Escribes un cliente delgado sobre `httpx` en lugar del SDK a propósito. Mantiene visible el JSON de la request, es trivial de mockear con `httpx.MockTransport` y funciona a través de un gateway si todavía no tienes una key directa de TypeSafe. El SDK está bien para los ejercicios siguientes; aquí necesitas ver el cable.

Esta es la primera carpeta de `jev-lab`, el repo que reúne todos los ejercicios del módulo 10.

## Contexto

Reutiliza 20–30 tickets del dataset de tu `support-ticket-router` del módulo 1, o escríbelos. Ponlos en `data/tickets.jsonl`:

```json

```

Graba respuestas **reales** una vez si tienes key (`python triage.py record`), o escribe a mano tres fixtures de respuesta que sigan exactamente el schema de response de la lección 02. Los tests leen solo fixtures.

<AcceptanceCriteria>

- [ ] `jev_client.py` expone `JevClient(api_key, base_url, transport=None, model="jev-latest")` con un método `system_one(state, questions) -> SystemOneResponse` que hace POST a `/v1/systemone` con `Authorization: Bearer`
- [ ] `SystemOneResponse`, `ChoiceAnswer`, `ScoreAnswer` y `NoulAnswer` son modelos Pydantic v2; parsear un fixture con un tipo de respuesta desconocido lanza un error de validación
- [ ] Las tres preguntas de triage se definen una sola vez como un dict a nivel de módulo y se envían en una única request
- [ ] Una respuesta 422 lanza `JevValidationError` con la lista `detail` del body; el CLI imprime la ruta del campo problemático y sale con código 2
- [ ] Una respuesta 429 o 529 se reintenta con backoff exponencial (base 0.5 s, máximo 4 intentos), respetando `Retry-After` cuando está presente; un quinto fallo lanza `JevRateLimited`
- [ ] 400 y 401 no se reintentan
- [ ] `python triage.py run data/tickets.jsonl` imprime una línea por ticket: id, departamento, confianza, score de frustración, noul de urgencia y una decisión (`auto`, `confirm`, `human`) usando umbrales de `config.py`
- [ ] Los tests usan `httpx.MockTransport` y fixtures en `tests/fixtures/`; ningún test necesita `TYPESAFE_API_KEY`; `pytest` pasa en menos de 2 segundos
- [ ] Toda decisión registrada incluye el campo `model` de la response y `usage.input_tokens`

</AcceptanceCriteria>

```python
# 01-triage/jev_client.py
from __future__ import annotations

import time
from typing import Any, Literal

import httpx
from pydantic import BaseModel, Field

BASE_URL = "https://api.typesafe.ai"


class ChoiceAnswer(BaseModel):
    type: Literal["choice"]
    choice: str
    confidence: float
    probabilities: dict[str, float]


class ScoreAnswer(BaseModel):
    type: Literal["score"]
    score: float
    confidence: float
    legend: dict[str, Any]
    probabilities: dict[str, float]


class NoulAnswer(BaseModel):
    type: Literal["noul"]
    noul: float


Answer = ChoiceAnswer | ScoreAnswer | NoulAnswer


class Usage(BaseModel):
    input_tokens: int
    output_tokens: int


class SystemOneResponse(BaseModel):
    model: str
    answers: dict[str, Answer] = Field(discriminator="type")
    usage: Usage


class JevError(Exception): ...


class JevValidationError(JevError):
    def __init__(self, detail: list[dict[str, Any]]):
        super().__init__(f"422: {detail}")
        self.detail = detail


class JevRateLimited(JevError): ...


class JevClient:
    def __init__(self, api_key: str, base_url: str = BASE_URL, transport: httpx.BaseTransport | None = None,
                 model: str = "jev-latest", max_attempts: int = 4, base_delay: float = 0.5):
        self._http = httpx.Client(base_url=base_url, transport=transport, timeout=30.0,
                                  headers={"Authorization": f"Bearer {api_key}"})
        self.model, self.max_attempts, self.base_delay = model, max_attempts, base_delay

    def system_one(self, state: str | dict | list, questions: dict[str, dict]) -> SystemOneResponse:
        body = {"model": self.model, "state": state, "questions": questions}
        for attempt in range(self.max_attempts):
            resp = self._http.post("/v1/systemone", json=body)
            if resp.status_code == 200:
                return SystemOneResponse.model_validate(resp.json())
            if resp.status_code == 422:
                raise JevValidationError(resp.json().get("detail", []))
            if resp.status_code in (429, 529):
                # TODO(you): sleep base_delay * 2**attempt, or Retry-After if present, then continue
                raise NotImplementedError
            resp.raise_for_status()  # 400, 401, 413, 415: do not retry
        raise JevRateLimited(f"gave up after {self.max_attempts} attempts")
```
