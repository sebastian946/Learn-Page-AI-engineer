## Goal

Build a small ticket-triage CLI on top of Jev and test it the way you would test any HTTP client: with recorded responses and no network. Given a ticket, the CLI asks three questions in **one** request (department Choice, frustration Score, urgency Noul), prints a typed decision, and behaves correctly when the API returns 422 or 429.

You write a thin client over `httpx` rather than the SDK on purpose. It keeps the request JSON visible, it is trivial to mock with `httpx.MockTransport`, and it works through a gateway if you do not have a direct TypeSafe key yet. The SDK is fine for the later exercises; here you need to see the wire.

This is the first folder of `jev-lab`, the repo that collects all Module 10 exercises.

## Context

Reuse 20–30 tickets from your Module 1 `support-ticket-router` dataset, or write them. Put them in `data/tickets.jsonl`:

```json
{"id": "t-001", "subject": "Charged twice", "message": "I see two charges of $49 for order A-104. Please refund one today."}
```

Record **real** responses once if you have a key (`python triage.py record`), or hand-write three fixture responses that follow the response schema from lesson 02 exactly. Tests read fixtures only.

<AcceptanceCriteria>

- [ ] `jev_client.py` exposes `JevClient(api_key, base_url, transport=None, model="jev-latest")` with a `system_one(state, questions) -> SystemOneResponse` method that POSTs to `/v1/systemone` with `Authorization: Bearer`
- [ ] `SystemOneResponse`, `ChoiceAnswer`, `ScoreAnswer` and `NoulAnswer` are Pydantic v2 models; parsing a fixture with an unknown answer type raises a validation error
- [ ] The three triage questions are defined once as a module-level dict and sent in a single request
- [ ] A 422 response raises `JevValidationError` carrying the `detail` list from the body; the CLI prints the offending field path and exits with code 2
- [ ] A 429 or 529 response is retried with exponential backoff (base 0.5 s, max 4 attempts), honouring `Retry-After` when present; a 5th failure raises `JevRateLimited`
- [ ] 400 and 401 are not retried
- [ ] `python triage.py run data/tickets.jsonl` prints one line per ticket: id, department, confidence, frustration score, urgency noul, and a decision (`auto`, `confirm`, `human`) using thresholds from `config.py`
- [ ] Tests use `httpx.MockTransport` and fixtures in `tests/fixtures/`; no test needs `TYPESAFE_API_KEY`; `pytest` passes in under 2 seconds
- [ ] Every logged decision includes the response `model` field and `usage.input_tokens`

</AcceptanceCriteria>

```python
# 01-triage/jev_client.py
from __future__ import annotations

import time
from typing import Any, Literal

import httpx
from pydantic import BaseModel, Field

BASE_URL = "https://api.typesafe.ai"


class ChoiceAnswer(BaseModel):
    type: Literal["choice"]
    choice: str
    confidence: float
    probabilities: dict[str, float]


class ScoreAnswer(BaseModel):
    type: Literal["score"]
    score: float
    confidence: float
    legend: dict[str, Any]
    probabilities: dict[str, float]


class NoulAnswer(BaseModel):
    type: Literal["noul"]
    noul: float


Answer = ChoiceAnswer | ScoreAnswer | NoulAnswer


class Usage(BaseModel):
    input_tokens: int
    output_tokens: int


class SystemOneResponse(BaseModel):
    model: str
    answers: dict[str, Answer] = Field(discriminator="type")
    usage: Usage


class JevError(Exception): ...


class JevValidationError(JevError):
    def __init__(self, detail: list[dict[str, Any]]):
        super().__init__(f"422: {detail}")
        self.detail = detail


class JevRateLimited(JevError): ...


class JevClient:
    def __init__(self, api_key: str, base_url: str = BASE_URL, transport: httpx.BaseTransport | None = None,
                 model: str = "jev-latest", max_attempts: int = 4, base_delay: float = 0.5):
        self._http = httpx.Client(base_url=base_url, transport=transport, timeout=30.0,
                                  headers={"Authorization": f"Bearer {api_key}"})
        self.model, self.max_attempts, self.base_delay = model, max_attempts, base_delay

    def system_one(self, state: str | dict | list, questions: dict[str, dict]) -> SystemOneResponse:
        body = {"model": self.model, "state": state, "questions": questions}
        for attempt in range(self.max_attempts):
            resp = self._http.post("/v1/systemone", json=body)
            if resp.status_code == 200:
                return SystemOneResponse.model_validate(resp.json())
            if resp.status_code == 422:
                raise JevValidationError(resp.json().get("detail", []))
            if resp.status_code in (429, 529):
                # TODO(you): sleep base_delay * 2**attempt, or Retry-After if present, then continue
                raise NotImplementedError
            resp.raise_for_status()  # 400, 401, 413, 415: do not retry
        raise JevRateLimited(f"gave up after {self.max_attempts} attempts")
```
