## Goal

Build a promptfoo suite for a ticket triage prompt that returns JSON with `category` and `priority`. The suite has two layers:

1. **Example-based tests** with gold labels, like the ones you know from Module 3.
2. **Metamorphic tests** generated from source cases by code: invariance relations (name swap, typos, polite filler, reordered sentences, translation) and directional relations (adding a legal threat or an outage keyword must not lower priority; adding "I do not want a refund" must not produce `billing_refund`).

Then you run the suite against two models and compare not just accuracy but **violation rates per relation**. That is the kind of evidence the capstone needs: a cheaper model that matches on clean inputs but breaks invariance on noisy ones is a migration risk.

This is folder `03-metamorphic/` of `llm-eval-lab`. If you prefer Inspect AI, you may implement the same design with a custom scorer; the acceptance criteria stay the same.

## Context

Your triage prompt returns exactly this JSON:

```json
{"category": "billing_refund", "priority": "high"}
```

Categories: `billing_refund`, `shipping`, `account`, `product_question`, `legal_threat`. Priorities: `low`, `normal`, `high`, `urgent`.

Start with 40 hand-labeled **source cases** in `sources.jsonl` (reuse tickets from exercise 03 and add priorities). Then generate follow-up cases with code. Some relations can be checked inside promptfoo because the expected value follows from the source's gold label (for example, a name swap must keep the gold category). Others compare the **two outputs** with no gold label at all (for example, priority after adding a legal threat must be greater than or equal to priority before). promptfoo evaluates one test at a time, so you check those with a small script over the results file.

<AcceptanceCriteria>

- [ ] `prompts/triage.txt` and `promptfooconfig.yaml` run against two models (two providers, or two tiers of one provider) with temperature 0
- [ ] At least 40 source cases with gold category and priority; at least 8 relations implemented in `generate_mr_tests.py` (at least 5 invariance and 3 directional)
- [ ] Transforms are deterministic code (seeded); any LLM-generated paraphrase or translation is cached and at least 20 of them were spot-checked by you, with results noted in the README
- [ ] Generated tests carry `metadata` with `source_id`, `relation` and `kind` (`source`, `invariance`, `directional`)
- [ ] Every test asserts valid JSON with allowed values; gold-anchored relations assert the expected category with a `javascript` assertion
- [ ] `check_relations.py` reads the promptfoo output file, pairs follow-up results with their source result per provider, and computes the violation rate per relation with a Wilson CI
- [ ] A self-consistency baseline is reported: each source case run twice (`--repeat 2`), and the rate at which the output changes with no transform
- [ ] `REPORT.md` has a table of accuracy and violation rate per relation per model, highlights relations where the models differ beyond their CIs, and lists 5 concrete violation examples
- [ ] The suite runs in CI on changes to `prompts/` with a cost-bounded subset (for example 10 sources × all relations)

</AcceptanceCriteria>

```python
# 03-metamorphic/generate_mr_tests.py
import json
import random
from dataclasses import dataclass
from pathlib import Path
from typing import Callable, Literal

import yaml

rng = random.Random(42)


@dataclass
class Relation:
    name: str
    kind: Literal["invariance", "directional"]
    transform: Callable[[str], str]
    expected_category: Callable[[str], str | None]  # from gold; None = checked offline only


def typos(text: str, rate: float = 0.05) -> str:
    chars = list(text)
    for i in range(len(chars) - 1):
        if chars[i].isalpha() and rng.random() < rate:
            chars[i], chars[i + 1] = chars[i + 1], chars[i]
    return "".join(chars)


RELATIONS: list[Relation] = [
    Relation("typos_5pct", "invariance", typos, lambda gold: gold),
    Relation("polite_filler", "invariance", lambda t: "Hello team, hope you are well. " + t, lambda gold: gold),
    Relation("legal_threat_priority", "directional",
             lambda t: t + " If this is not solved by Friday my lawyer will contact you.", lambda gold: None),
    # TODO(you): name swap, sentence reorder, translation (cached LLM call), outage keyword,
    #            explicit negation of refund, ALL CAPS
]


def test_case(vars_text: str, meta: dict, expected_category: str | None) -> dict:
    asserts = []
    if expected_category:
        asserts.append({"type": "javascript",
                        "value": f"JSON.parse(output).category === '{expected_category}'"})
    return {"vars": {"ticket": vars_text}, "metadata": meta, "assert": asserts}


def main() -> None:
    sources = [json.loads(l) for l in Path("sources.jsonl").read_text("utf-8").splitlines()]
    tests = []
    for s in sources:
        tests.append(test_case(s["text"], {"source_id": s["id"], "relation": "none", "kind": "source"},
                               s["category"]))
        for r in RELATIONS:
            new_text = r.transform(s["text"])
            if new_text == s["text"]:
                continue
            meta = {"source_id": s["id"], "relation": r.name, "kind": r.kind}
            tests.append(test_case(new_text, meta, r.expected_category(s["category"])))
    Path("tests/generated.yaml").write_text(yaml.safe_dump(tests, sort_keys=False), "utf-8")
    print(f"wrote {len(tests)} tests")


if __name__ == "__main__":
    main()
```
