## Objetivo

Construye una suite de promptfoo para un prompt de triage de tickets que devuelve JSON con `category` y `priority`. La suite tiene dos capas:

1. **Pruebas basadas en ejemplos** con etiquetas gold, como las que conoces del módulo 3.
2. **Pruebas metamórficas** generadas por código a partir de casos fuente: relaciones de invariancia (cambio de nombre, errores de tipeo, relleno cortés, oraciones reordenadas, traducción) y relaciones direccionales (agregar una amenaza legal o una palabra de caída del servicio no debe bajar la prioridad; agregar "no quiero un reembolso" no debe producir `billing_refund`).

Luego corres la suite contra dos modelos y comparas no solo la accuracy sino las **tasas de violación por relación**. Ese es el tipo de evidencia que necesita el proyecto final: un modelo más barato que iguala con entradas limpias pero rompe la invariancia con entradas ruidosas es un riesgo de migración.

Esta es la carpeta `03-metamorphic/` de `llm-eval-lab`. Si prefieres Inspect AI, puedes implementar el mismo diseño con un scorer personalizado; los criterios de aceptación son los mismos.

## Contexto

Tu prompt de triage devuelve exactamente este JSON:

```json
{"category": "billing_refund", "priority": "high"}
```

Categorías: `billing_refund`, `shipping`, `account`, `product_question`, `legal_threat`. Prioridades: `low`, `normal`, `high`, `urgent`.

Empieza con 40 **casos fuente** etiquetados a mano en `sources.jsonl` (reutiliza tickets del ejercicio 03 y agrega prioridades). Luego genera casos derivados con código. Algunas relaciones se pueden verificar dentro de promptfoo porque el valor esperado se desprende de la etiqueta gold de la fuente (por ejemplo, un cambio de nombre debe conservar la categoría gold). Otras comparan **las dos salidas** sin ninguna etiqueta gold (por ejemplo, la prioridad tras agregar una amenaza legal debe ser mayor o igual que antes). promptfoo evalúa una prueba a la vez, así que esas las verificas con un script pequeño sobre el archivo de resultados.

```python
# 03-metamorphic/generate_mr_tests.py
import json
import random
from dataclasses import dataclass
from pathlib import Path
from typing import Callable, Literal

import yaml

rng = random.Random(42)


@dataclass
class Relation:
    name: str
    kind: Literal["invariance", "directional"]
    transform: Callable[[str], str]
    expected_category: Callable[[str], str | None]  # from gold; None = checked offline only


def typos(text: str, rate: float = 0.05) -> str:
    chars = list(text)
    for i in range(len(chars) - 1):
        if chars[i].isalpha() and rng.random() < rate:
            chars[i], chars[i + 1] = chars[i + 1], chars[i]
    return "".join(chars)


RELATIONS: list[Relation] = [
    Relation("typos_5pct", "invariance", typos, lambda gold: gold),
    Relation("polite_filler", "invariance", lambda t: "Hello team, hope you are well. " + t, lambda gold: gold),
    Relation("legal_threat_priority", "directional",
             lambda t: t + " If this is not solved by Friday my lawyer will contact you.", lambda gold: None),
    # TODO(you): name swap, sentence reorder, translation (cached LLM call), outage keyword,
    #            explicit negation of refund, ALL CAPS
]


def test_case(vars_text: str, meta: dict, expected_category: str | None) -> dict:
    asserts = []
    if expected_category:
        asserts.append({"type": "javascript",
                        "value": f"JSON.parse(output).category === '{expected_category}'"})
    return {"vars": {"ticket": vars_text}, "metadata": meta, "assert": asserts}


def main() -> None:
    sources = [json.loads(l) for l in Path("sources.jsonl").read_text("utf-8").splitlines()]
    tests = []
    for s in sources:
        tests.append(test_case(s["text"], {"source_id": s["id"], "relation": "none", "kind": "source"},
                               s["category"]))
        for r in RELATIONS:
            new_text = r.transform(s["text"])
            if new_text == s["text"]:
                continue
            meta = {"source_id": s["id"], "relation": r.name, "kind": r.kind}
            tests.append(test_case(new_text, meta, r.expected_category(s["category"])))
    Path("tests/generated.yaml").write_text(yaml.safe_dump(tests, sort_keys=False), "utf-8")
    print(f"wrote {len(tests)} tests")


if __name__ == "__main__":
    main()
```
