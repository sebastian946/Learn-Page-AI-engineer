## Objetivo

Construye un agente de soporte con LangGraph para una empresa de logística que pueda consultar pedidos, reprogramar entregas y emitir reembolsos. Los reembolsos mueven dinero, así que **ningún reembolso se ejecuta sin una decisión humana**. El operador puede aprobar, rechazar o editar los argumentos (por ejemplo, bajar el monto) antes de que la herramienta se ejecute.

Este es el primer commit del repo `langgraph-hitl-agent`. La lección 12 le agrega guardas de bucle y límites de costo, y la lección 14 agrega una suite de evals de trayectoria, así que mantén la estructura limpia.

Vas a practicar:

- Estado tipado con `add_messages`, un router propio y enrutamiento con `Command`.
- `interrupt()` y `Command(resume=...)` con un checkpointer.
- Reemplazar un mensaje de la IA por id para aplicar una edición.
- Probar un agente **sin llamar a la API**, usando un modelo fake con guion. Es la versión para agentes de mockear un backend en Playwright: determinista, rápido y gratis.

Tiempo estimado: de 60 a 90 minutos.

## Requisitos

Herramientas (en `tools.py`, decoradas con `@tool` de `langchain_core.tools`, respaldadas por un dict de pedidos en memoria):

- `get_order(order_id)`: devuelve estado, transportista, fecha de entrega y total en centavos, o el contrato de error `{"error": {"code": "ORDER_NOT_FOUND", ...}}`.
- `reschedule_delivery(order_id, new_date, idempotency_key)`: rechaza fechas pasadas con `INVALID_DATE`. La misma key dos veces devuelve el primer resultado en lugar de reprogramar otra vez.
- `issue_refund(order_id, amount_cents, reason, idempotency_key)`: rechaza montos mayores al total del pedido con `AMOUNT_EXCEEDS_TOTAL`. Idempotente por key.

Política:

- Cualquier mensaje de la IA que contenga `issue_refund` va a un nodo `approval` que llama a `interrupt()`.
- Decisiones: `{"action": "approve"}`, `{"action": "reject", "reason": "..."}`, `{"action": "edit", "args": {...}}`.
- Rechazar produce un `ToolMessage` con código de error `REJECTED_BY_HUMAN` para **cada** tool call pendiente y luego vuelve al agente.
- Cada tool call ejecutada se agrega a una lista de auditoría en el estado (`tool_log`) con el nombre de la herramienta, los argumentos y el código de resultado.

from langgraph.graph import StateGraph, START, END
from langgraph.prebuilt import ToolNode
from .state import AgentState
from .tools import get_order, issue_refund  # , reschedule_delivery
from .approval import approval, RISKY_TOOLS

TOOLS = [get_order, issue_refund]
SYSTEM = "You are a logistics support agent. Use tools for every fact. Refunds need a reason."


def build_graph(llm, checkpointer):
    """llm: anything with .invoke(messages) -> AIMessage (already bound to TOOLS)."""

    def agent(state: AgentState) -> dict:
        response = llm.invoke([("system", SYSTEM), *state["messages"]])
        return {"messages": [response], "step_count": state.get("step_count", 0) + 1}

    def route(state: AgentState) -> str:
        # TODO: END if no tool calls, "approval" if any risky tool, else "tools"
        raise NotImplementedError

    builder = StateGraph(AgentState)
    builder.add_node("agent", agent)
    builder.add_node("approval", approval)
    builder.add_node("tools", ToolNode(TOOLS))
    builder.add_edge(START, "agent")
    builder.add_conditional_edges("agent", route, ["tools", "approval", END])
    builder.add_edge("tools", "agent")  # TODO: add an audit node between tools and agent
    return builder.compile(checkpointer=checkpointer)

from langchain_core.messages import AIMessage


class ScriptedModel:
    """Returns pre-written AIMessages in order. Records what it was called with."""

    def __init__(self, responses: list[AIMessage]):
        self.responses = list(responses)
        self.calls: list[list] = []

    def invoke(self, messages, **kwargs) -> AIMessage:
        self.calls.append(messages)
        return self.responses.pop(0)


def refund_call(amount_cents: int, call_id: str = "call_1") -> AIMessage:
    return AIMessage(content="", tool_calls=[{

        "args": {"order_id": "ORD-1042", "amount_cents": amount_cents,
                 "reason": "damaged", "idempotency_key": "t-1-refund"},
