## Goal

Build a LangGraph support agent for a logistics company that can look up orders, reschedule deliveries and issue refunds. Refunds move money, so **no refund runs without a human decision**. The operator can approve, reject, or edit the arguments (for example lower the amount) before the tool executes.

This is the first commit of the `langgraph-hitl-agent` repo. Lesson 12 adds loop guards and cost caps to it, and lesson 14 adds a trajectory eval suite, so keep the structure clean.

You will practice:

- Typed state with `add_messages`, a custom router, and `Command` routing.
- `interrupt()` and `Command(resume=...)` with a checkpointer.
- Replacing an AI message by id to apply an edit.
- Testing an agent **without calling the API**, using a scripted fake model. This is the agent version of mocking a backend in Playwright: deterministic, fast, free.

Time box: 60 to 90 minutes.

## Requirements

Tools (in `tools.py`, decorated with `@tool` from `langchain_core.tools`, backed by an in-memory dict of orders):

- `get_order(order_id)`: returns status, carrier, delivery date and total in cents, or the error contract `{"error": {"code": "ORDER_NOT_FOUND", ...}}`.
- `reschedule_delivery(order_id, new_date, idempotency_key)`: rejects past dates with `INVALID_DATE`. Same key twice returns the first result instead of rescheduling again.
- `issue_refund(order_id, amount_cents, reason, idempotency_key)`: refuses amounts above the order total with `AMOUNT_EXCEEDS_TOTAL`. Idempotent by key.

Policy:

- Any AI message containing `issue_refund` goes to an `approval` node that calls `interrupt()`.
- Decisions: `{"action": "approve"}`, `{"action": "reject", "reason": "..."}`, `{"action": "edit", "args": {...}}`.
- Reject produces a `ToolMessage` with error code `REJECTED_BY_HUMAN` for **every** pending tool call, then returns to the agent.
- Every executed tool call is appended to an audit list in state (`tool_log`) with the tool name, args and result code.

<AcceptanceCriteria>

- [ ] `build_graph(llm, checkpointer)` returns a compiled graph; the model is injected so tests can pass a fake.
- [ ] `get_order` and `reschedule_delivery` run without any interrupt.
- [ ] A refund request pauses the run: the result contains `__interrupt__` with tool name, args and tool call id, and `graph.get_state(config).next == ("approval",)`.
- [ ] Approve: the refund executes exactly once, and the final AI message confirms it.
- [ ] Edit: the refund executes with the edited `amount_cents`, and the stored AI message shows the edited args (same message id, no duplicate).
- [ ] Reject: no refund executes; the agent receives a `REJECTED_BY_HUMAN` tool result and replies to the customer.
- [ ] Resuming twice with the same idempotency key never creates two refunds.
- [ ] `python -m hitl_agent.cli` runs a conversation and prompts the operator in the terminal (approve / reject / edit).
- [ ] `pytest` passes with no network access and no `ANTHROPIC_API_KEY` set.

</AcceptanceCriteria>

from langgraph.graph import StateGraph, START, END
from langgraph.prebuilt import ToolNode
from .state import AgentState
from .tools import get_order, issue_refund  # , reschedule_delivery
from .approval import approval, RISKY_TOOLS

TOOLS = [get_order, issue_refund]
SYSTEM = "You are a logistics support agent. Use tools for every fact. Refunds need a reason."


def build_graph(llm, checkpointer):
    """llm: anything with .invoke(messages) -> AIMessage (already bound to TOOLS)."""

    def agent(state: AgentState) -> dict:
        response = llm.invoke([("system", SYSTEM), *state["messages"]])
        return {"messages": [response], "step_count": state.get("step_count", 0) + 1}

    def route(state: AgentState) -> str:
        # TODO: END if no tool calls, "approval" if any risky tool, else "tools"
        raise NotImplementedError

    builder = StateGraph(AgentState)
    builder.add_node("agent", agent)
    builder.add_node("approval", approval)
    builder.add_node("tools", ToolNode(TOOLS))
    builder.add_edge(START, "agent")
    builder.add_conditional_edges("agent", route, ["tools", "approval", END])
    builder.add_edge("tools", "agent")  # TODO: add an audit node between tools and agent
    return builder.compile(checkpointer=checkpointer)

from langchain_core.messages import AIMessage


class ScriptedModel:
    """Returns pre-written AIMessages in order. Records what it was called with."""

    def __init__(self, responses: list[AIMessage]):
        self.responses = list(responses)
        self.calls: list[list] = []

    def invoke(self, messages, **kwargs) -> AIMessage:
        self.calls.append(messages)
        return self.responses.pop(0)


def refund_call(amount_cents: int, call_id: str = "call_1") -> AIMessage:
    return AIMessage(content="", tool_calls=[{

        "args": {"order_id": "ORD-1042", "amount_cents": amount_cents,
                 "reason": "damaged", "idempotency_key": "t-1-refund"},
