# Examen del módulo 0

Este examen comprueba que sabes razonar sobre el mercado laboral de AI Engineer y sobre tu propio plan, no que memorizaste datos. Cubre:

- Los niveles de demanda de habilidades: lo casi universal (RAG, prompt engineering, integración de LLM, Python), lo muy común (agentes, evals, FastAPI, Docker/CI-CD, AWS, bases de datos vectoriales) y lo secundario (fine-tuning, plataformas de datos).
- Las tres familias de roles: AI-first, AI-support y ML Engineer, y dónde encaja mejor un SDET senior.
- Cómo se corresponden tus habilidades de QA con la ingeniería de IA: golden datasets, umbrales, gates de CI, no determinismo.
- Cómo leer una oferta de empleo: el método de las cuatro pasadas, imprescindibles vs deseables, señales de alerta.
- Qué contiene un buen README de portafolio y qué revisa un evaluador en dos minutos.
- Cómo funcionan la plataforma, el gate del examen, el repaso espaciado y el banco de entrevistas.

Hay 14 preguntas: opción única, selección múltiple, ordenar pasos y lectura breve de código. Tienes 25 minutos. El puntaje mínimo para aprobar es **70 %**, y aprobar desbloquea el Módulo 1.

**Cómo prepararte:** relee las secciones de "Errores comunes" de cada lección y asegúrate de que tu repo `ai-engineer-portfolio` esté subido con el linter de README en verde. Varias preguntas describen situaciones en lugar de pedir definiciones. Si no apruebas, lee todas las explicaciones, repasa la lección relacionada y vuelve a intentarlo. Las preguntas y las opciones se mezclan en cada intento.
