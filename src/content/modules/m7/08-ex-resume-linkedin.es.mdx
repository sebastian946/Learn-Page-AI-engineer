## Objetivo

Reescribe tus bullets del CV, tu titular de LinkedIn y tu sección "Acerca de" usando el mapeo de módulo a palabras clave de la lección anterior. Luego mide el resultado contra tres ofertas reales, como medirías la cobertura de pruebas.

Producirás una carpeta `career/` versionada en el repo central de tu portafolio (`ai-engineer-portfolio`, del Módulo 0). El contenido del CV vive como markdown y YAML para que puedas comparar versiones, adaptarlo por oferta y generar un PDF.

Contexto: la lección anterior te dio una fórmula (acción + qué + tecnología + resultado medido) y un chequeador de cobertura. Aquí aplicas ambos a tu propia historia. Espera que el primer borrador sea débil. La segunda pasada, donde cada número se verifica contra un artefacto, es donde está el valor.

Nota: si postulas al mercado en inglés, escribe el contenido final en inglés. Las plantillas de abajo ya están en inglés.

Pasos:

1. **Reúne evidencia (15 min).** Para cada capstone, abre la tabla de resultados de su README, el reporte de evals y el análisis de costos. Anota cada número medido con un enlace a su origen. Este es tu archivo de evidencia.
2. **Elige tres ofertas objetivo (10 min).** Ofertas reales y vigentes para roles que aceptarías. Guarda el texto en archivos (las ofertas cambian o desaparecen).
3. **Redacta los bullets (20 min).** 2 a 3 bullets por capstone, 3 a 5 por rol de SDET. Usa la fórmula. Cada número debe aparecer en tu archivo de evidencia.
4. **Corre la cobertura (10 min).** Usa el chequeador contra cada oferta. Corrige las brechas honestas (usaste la habilidad pero no la mencionaste). Anota las brechas deshonestas (te falta la habilidad) como temas de aprendizaje, no como líneas del CV.
5. **LinkedIn (15 min).** Titular, "Acerca de", plan de la sección Destacados, orden de las aptitudes principales.
6. **Lectura en voz alta (5 min).** Lee el resultado en voz alta. Todo lo que suene a responsabilidad en lugar de resultado se reescribe.

<AcceptanceCriteria>

- [ ] `career/evidence.md` lista cada número usado en el CV, cada uno con un enlace al artefacto del repo que lo prueba.
- [ ] `career/resume.yaml` tiene titular, resumen de 3 líneas, habilidades agrupadas, proyectos (el capstone final primero) y experiencia reescrita.
- [ ] Cada bullet sigue acción + qué + tecnología + resultado medido, y ocupa menos de 2 líneas.
- [ ] No aparece en el CV ninguna herramienta que no hayas usado en un proyecto o trabajo.
- [ ] `career/postings/` contiene 3 ofertas guardadas y `career/coverage.md` muestra la cobertura por oferta antes y después de la reescritura, con las brechas restantes listadas.
- [ ] `career/linkedin.md` tiene un titular de menos de 220 caracteres, un "Acerca de" de 3 párrafos que termina con un llamado a la acción, un plan de Destacados y las 10 aptitudes principales ordenadas.
- [ ] El script de cobertura corre con `python career/check.py` e imprime una tabla.

</AcceptanceCriteria>

```python
# career/check.py - coverage of each saved posting vs the resume
from pathlib import Path
import yaml
from keywords import found  # the KEYWORDS + found() function from lesson 07

def resume_text(path: Path) -> str:
    data = yaml.safe_load(path.read_text(encoding="utf-8"))
    parts = [data["headline"], data["summary"]]
    parts += [s for group in data["skills"].values() for s in group]
    for section in ("projects", "experience"):
        parts += [b for item in data[section] for b in item["bullets"]]
    return "\n".join(parts)

def main() -> None:
    resume = found(resume_text(Path("career/resume.yaml")))
    print(f"{'posting':40} {'coverage':>8}  missing")
    for p in sorted(Path("career/postings").glob("*.txt")):
        wanted = found(p.read_text(encoding="utf-8"))
        pct = round(100 * len(wanted & resume) / max(len(wanted), 1))
        print(f"{p.stem:40} {pct:>7}%  {', '.join(sorted(wanted - resume))}")

if __name__ == "__main__":
    main()
```
