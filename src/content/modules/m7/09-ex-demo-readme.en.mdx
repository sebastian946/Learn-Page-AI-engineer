## Goal

Turn the final capstone repo, `multi-tenant-ai-platform`, into something a reviewer understands in 90 seconds. You will record a scripted demo GIF, write the final README, add an architecture doc with ADRs, and make the results table regenerate from real eval output so it never goes stale.

Do this exercise after the capstone works end to end (or near the end of capstone day 5). A README written before the system works ends up describing intentions, not results.

The key engineering idea: **README numbers are build artifacts.** As an SDET you would never hand-edit a test report. Same here. `make eval` writes `reports/latest.json`; a script renders the README's results table from it between two marker comments. CI fails if the README is out of date.

The demo script (aim for 20 to 25 seconds, no narration):

1. Log in as a user from Firm A. Ask a real question. Show the streamed answer with citations.
2. Click one citation; the source passage opens.
3. Ask the agent to do something with a tool (for example, "create a review task for this clause"); show the approval prompt and approve it.
4. Switch to Firm B. Ask for Firm A's canary document. Show "I don't have information about that".
5. Open the trace for the last request: spans for retrieval, re-rank, LLM, with `tenant_id` visible.
6. End on the cost dashboard filtered by tenant.

```python
# scripts/render_readme.py - regenerate the results table from the latest eval report
import json
import sys
from pathlib import Path

START, END = "<!-- results:start -->", "<!-- results:end -->"

ROWS = [  # (label, report key, target, format, higher_is_better)
    ("Faithfulness", "rag.faithfulness", 0.90, "{:.2f}", True),
    ("Context recall", "rag.context_recall", 0.85, "{:.2f}", True),
    ("Agent tool-sequence accuracy", "agent.trajectory_exact", 0.80, "{:.2f}", True),
    ("Cross-tenant leaks", "isolation.leaks", 0, "{:d}", False),
    ("p95 first token (s)", "perf.p95_ttft_s", 1.5, "{:.2f}", False),
    ("Cost per 1k requests (USD)", "cost.per_1k_usd", 4.00, "{:.2f}", False),
]

def get(report: dict, dotted: str):
    node = report
    for part in dotted.split("."):
        node = node[part]
    return node

def table(report: dict) -> str:
    meta = report["meta"]
    lines = [f"_Eval set {meta['dataset_version']} ({meta['n_questions']} questions), run {meta['date']}, commit {meta['commit'][:7]}_", "",
             "| Metric | Target | Current | Status |", "|---|---|---|---|"]
    for label, key, target, fmt, higher in ROWS:
        value = get(report, key)
        ok = value >= target if higher else value <= target
        lines.append(f"| {label} | {fmt.format(target)} | {fmt.format(value)} | {'pass' if ok else 'FAIL'} |")
    return "\n".join(lines)

def render(readme: str, report: dict) -> str:
    head, rest = readme.split(START, 1)
    _, tail = rest.split(END, 1)
    return f"{head}{START}\n{table(report)}\n{END}{tail}"

if __name__ == "__main__":
    readme_path, report = Path("README.md"), json.loads(Path("reports/latest.json").read_text())
    new = render(readme_path.read_text(encoding="utf-8"), report)
    if "--check" in sys.argv:
        sys.exit(0 if new == readme_path.read_text(encoding="utf-8") else "README results are stale: run make readme")
    readme_path.write_text(new, encoding="utf-8")
```
