## Objetivo

Convierte el repo del capstone final, `multi-tenant-ai-platform`, en algo que un revisor entienda en 90 segundos. Grabarás un GIF de demo con guion, escribirás el README final, agregarás un documento de arquitectura con ADRs y harás que la tabla de resultados se regenere a partir de la salida real de los evals para que nunca quede desactualizada.

Haz este ejercicio cuando el capstone funcione de punta a punta (o cerca del final del día 5 del capstone). Un README escrito antes de que el sistema funcione termina describiendo intenciones, no resultados.

La idea de ingeniería clave: **los números del README son artefactos de build.** Como SDET nunca editarías a mano un reporte de pruebas. Aquí igual. `make eval` escribe `reports/latest.json`; un script genera la tabla de resultados del README a partir de él, entre dos comentarios marcadores. CI falla si el README está desactualizado.

El guion de la demo (apunta a 20 a 25 segundos, sin narración):

1. Inicia sesión como usuario del Bufete A. Haz una pregunta real. Muestra la respuesta en streaming con citas.
2. Haz clic en una cita; se abre el pasaje fuente.
3. Pídele al agente que haga algo con una herramienta (por ejemplo, "crea una tarea de revisión para esta cláusula"); muestra el pedido de aprobación y apruébalo.
4. Cambia al Bufete B. Pregunta por el documento canario del Bufete A. Muestra "No tengo información sobre eso".
5. Abre el trace de la última petición: spans de retrieval, re-rank y LLM, con el `tenant_id` visible.
6. Termina en el dashboard de costos filtrado por tenant.

```python
# scripts/render_readme.py - regenerate the results table from the latest eval report
import json
import sys
from pathlib import Path

START, END = "<!-- results:start -->", "<!-- results:end -->"

ROWS = [  # (label, report key, target, format, higher_is_better)
    ("Faithfulness", "rag.faithfulness", 0.90, "{:.2f}", True),
    ("Context recall", "rag.context_recall", 0.85, "{:.2f}", True),
    ("Agent tool-sequence accuracy", "agent.trajectory_exact", 0.80, "{:.2f}", True),
    ("Cross-tenant leaks", "isolation.leaks", 0, "{:d}", False),
    ("p95 first token (s)", "perf.p95_ttft_s", 1.5, "{:.2f}", False),
    ("Cost per 1k requests (USD)", "cost.per_1k_usd", 4.00, "{:.2f}", False),
]

def get(report: dict, dotted: str):
    node = report
    for part in dotted.split("."):
        node = node[part]
    return node

def table(report: dict) -> str:
    meta = report["meta"]
    lines = [f"_Eval set {meta['dataset_version']} ({meta['n_questions']} questions), run {meta['date']}, commit {meta['commit'][:7]}_", "",
             "| Metric | Target | Current | Status |", "|---|---|---|---|"]
    for label, key, target, fmt, higher in ROWS:
        value = get(report, key)
        ok = value >= target if higher else value <= target
        lines.append(f"| {label} | {fmt.format(target)} | {fmt.format(value)} | {'pass' if ok else 'FAIL'} |")
    return "\n".join(lines)

def render(readme: str, report: dict) -> str:
    head, rest = readme.split(START, 1)
    _, tail = rest.split(END, 1)
    return f"{head}{START}\n{table(report)}\n{END}{tail}"

if __name__ == "__main__":
    readme_path, report = Path("README.md"), json.loads(Path("reports/latest.json").read_text())
    new = render(readme_path.read_text(encoding="utf-8"), report)
    if "--check" in sys.argv:
        sys.exit(0 if new == readme_path.read_text(encoding="utf-8") else "README results are stale: run make readme")
    readme_path.write_text(new, encoding="utf-8")
```
